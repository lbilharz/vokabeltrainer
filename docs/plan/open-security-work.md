# Open security work

Status: planned ("package 2"). It should be done before a public start, for example before an App Store app.

The full report of the review is deliberately not in the repository, because the repository is public.
This document names only the areas.

## Areas

- Quantity limits per account
- Storage name of the recordings
- Sessions and passkeys
- Registration
- Push addresses
- Local data at logout
- Deleting and exporting an account

## Approach

1. Plan and implement each area on its own.
2. After each piece of work, update the architecture in `docs/architecture/`.
3. Describe only afterwards what changed. Descriptions of open gaps do not belong in the repository.
