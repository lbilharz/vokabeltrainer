# Documentation

These folders belong together. The rules for them are in `AGENTS.md`.

- `architecture/`: How the system is built today, and why.
- `plan/`: Work that is planned and not finished.
- `history/`: What was done, in which order, and for which reasons.

This first version describes the branch `neue-oberflaeche`.
It is based on the code and on the commit messages.
Quoted UI texts stay in German, because the app is German.
